# uni-rpc
Rust-based Discord Rich Presence tool that attempts to use information from external sources rather than directly interfacing with software. In development.


## HOW IT WORKS
In short, it makes requests to APIs such as Steam's and Last.FM's, and perhaps more to come. It'll report back to the IPC controller and then set your activity as informed. Eventually, more services will be supported, and more configurability will be allowed.
